# Contributing

Contributions are welcome.

## Good contributions

Useful contributions include:

- confirmed working Govee models
- screenshots with all personal values hidden
- improved setup steps
- troubleshooting notes
- translations
- safer Shortcut logic

## Add a supported model

If a model works, add it to the README with this format:

```markdown
- Govee Model Name / SKU — confirmed by @username
```

Please do not include your real device ID.

## Do not include secrets

Before opening an issue or pull request, check that you did not include:

- Govee API key
- real device ID
- personal email address
- screenshots with sensitive data

## Style

Keep instructions simple and practical. The target audience is people who want a working iPhone Shortcut, not developers only.
